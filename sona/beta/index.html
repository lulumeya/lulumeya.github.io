Sona 베타

Sona 써 보기

이 안내를 보낸 사람이 직접 만든 음악 앱이에요. Qobuz·Tidal 음악을 폰으로 듣거나, 집에 있는 네트워크 오디오(앞으로 "렌더러" 라고 불러요 — 네트워크로 음악을 받아 트는 스피커나 플레이어)로 보내서 들을 수 있어요. 아래 순서대로만 하면 첫 소리까지 가요.

내 기기를 골라 주세요. 자기 기기 부분만 읽으면 돼요.

아이폰 아이패드 안드로이드

시작 전에

  • Qobuz 나 Tidal 계정이 있으면 좋아요. 없으면 라디오만 들을 수 있어요. 둘 다 한국 공식 서비스가 아니라서 앱 안에서 새로 가입할 수는 없어요.
  • 아이폰·아이패드는 iOS 16 이상, 안드로이드는 9 이상이어야 해요.
  • 집에 렌더러가 없어도 괜찮아요. 대신 처음 켜고 설정 하나를 꼭 바꿔야 해요 (처음 켜면 → 2번).

아이폰에 설치하기

애플은 심사 없이 앱을 나눠 줄 때 "팀 안의 사람"에게만 줄 수 있어요. 그래서 먼저 팀 초대를 받고, 그다음 TestFlight(애플의 베타 앱 설치 도구)로 받아요. 메일이 두 번 와요.

  1. "App Store Connect 팀 초대" 메일을 열고 수락해요. 로그인은 초대받은 그 이메일의 Apple 계정으로 하세요. 다른 Apple 계정으로 수락해도 되는지는 확인되지 않았어요.

    스크린샷 자리Apple 에서 온 초대 메일. 가운데에 수락 버튼이 있고, 누르면 Apple 계정 로그인 화면이 떠요.
    ✅로그인까지 끝나면 수락된 거예요. 보낸 사람에게 "수락했어" 라고 알려 주세요. 그래야 다음 초대를 보낼 수 있어요.

    팀에 들어가면 App Store Connect 사이트에서 팀 이름과, 내 역할로 볼 수 있는 앱 목록이 보여요. 그 사이트에 들어갈 일은 없어요.

  2. App Store 에서 TestFlight 앱을 설치해요. Apple 이 만든 앱이에요.

    스크린샷 자리App Store 검색창에 "TestFlight" 를 넣으면 나오는 Apple 의 TestFlight 앱과 받기 버튼.
    ✅홈 화면에 TestFlight 아이콘이 생겨요.

  3. "TestFlight 초대" 메일이 오면 "TestFlight에서 보기" → 수락 → 설치.

    스크린샷 자리TestFlight 앱 안에 Sona 가 뜨고 설치 버튼이 보여요.
    ✅홈 화면에 Sona 아이콘이 생겨요.

  4. TestFlight 앱 → Sona → 자동 업데이트 켜기. 새 버전이 알아서 들어와요.

    스크린샷 자리TestFlight 앱의 Sona 화면. 자동 업데이트 스위치가 켜져 있어요.

아이패드에 설치하기

아이폰과 같은 앱이고 순서도 똑같아요. 아이패드에서는 가로·세로 다 돌아가요(아이폰은 세로 고정). 메일이 두 번 와요.

  1. "App Store Connect 팀 초대" 메일 → 수락. 로그인은 초대받은 그 이메일의 Apple 계정으로. 끝나면 보낸 사람에게 "수락했어" 라고 알려 주세요.

  2. App Store 에서 TestFlight 앱 설치(iPadOS 16 이상).

  3. "TestFlight 초대" 메일 → "TestFlight에서 보기" → 수락 → 설치.

    ✅홈 화면에 Sona 아이콘이 생겨요.

  4. TestFlight 앱 → Sona → 자동 업데이트 켜기.

각 단계가 어떤 화면인지는 아이폰 부분에 적어 두었어요. 화면이 같아요.

안드로이드에 설치하기

구글 플레이가 아니라 App Tester(구글의 테스트 앱 설치 도구)로 받아요. 플레이 밖에서 설치하는 것이라 중간에 경고가 두어 번 떠요. 아래대로 넘기면 돼요.

  1. 초대 메일을 열고 수락해요. 로그인은 아무 구글 계정이나 돼요. 초대는 30일 안에 받아야 해요.

    스크린샷 자리Firebase App Distribution 에서 온 초대 메일. 수락 버튼을 누르면 구글 로그인이 떠요.

  2. 안내에 따라 App Tester 앱을 설치해요.

    스크린샷 자리App Tester 설치 안내 화면. 설치 버튼이 보여요.
    ✅앱 목록에 App Tester 가 생겨요.

  3. "출처를 알 수 없는 앱 설치" 를 허용하라는 창이 뜨면 허용해요. 설치를 진행하는 앱(App Tester 또는 Chrome)마다 한 번만 물어요.

    스크린샷 자리"이 출처의 앱 허용" 스위치가 있는 설정 화면.

  4. App Tester 에서 Sona → 다운로드 → 설치.

    스크린샷 자리App Tester 안의 Sona 와 다운로드 버튼, 이어서 설치 확인 창.

  5. "안전하지 않은 앱" 같은 Play 프로텍트 경고가 뜨면 세부정보 → 무시하고 설치.

    삼성 폰이라면

    설정 → 보안 및 개인정보 보호 → 자동 차단(Auto Blocker) 이 켜져 있으면 설치가 막혀요. 잠시 끄고 설치한 뒤 다시 켜도 돼요.

    여기 적은 경고 문구와 메뉴 이름은 기기마다 조금 다를 수 있어요.

    ✅앱 목록에 Sona 가 생겨요.

처음 켜면

세 기기 공통이에요. 사진은 안드로이드 화면인데, 아이폰·아이패드도 화면 구성이 같아요. 로그인이나 안내 화면 없이 바로 홈이 떠요. 아래에 탭이 다섯 개 — 홈 / 검색 / 라이브러리 / 재생 / 설정.

첫 화면에 "tidal 동기화 실패: …" 알림이 잠깐 떠도

아직 로그인 전이라 그래요. 무시해도 돼요.

1. (아이폰·아이패드만) 로컬 네트워크 권한

처음 켜면 "로컬 네트워크의 기기를 찾고 연결하려고 합니다" 같은 창이 떠요(앱 설명 문구는 영어로 나와요). 렌더러로 들을 거면 허용. 폰으로만 들을 거면 허용하지 않아도 돼요. 나중에 바꾸려면 설정 → Sona → 로컬 네트워크.

2. 소리가 어디서 날지 고르기 — 가장 중요해요

홈 맨 위 카드가 지금 소리가 나갈 곳이에요. 앱은 처음에 렌더러로 보내도록 돼 있어서, 집에 렌더러가 없으면 이걸 바꿔야 소리가 나요.

안 바꾸면 재생을 눌러도 아무 반응이 없어요

오류 안내도 안 떠요(알려진 문제). "고장났나?" 싶으면 이 설정부터 보세요.

렌더러가 있다면 같은 시트의 "UPnP 렌더러" 목록에서 고르세요. 폰과 렌더러가 같은 Wi-Fi 에 있어야 하고, VPN 을 켜 두면 못 찾아요.

같은 설정이 설정 탭 → 재생 → 출력 에도 있어요.

3. 로그인 (Qobuz 나 Tidal 계정이 있을 때)

Tidal: "Tidal 로그인" 을 누르면 앱 안에서 Tidal 로그인 페이지가 열려요. 로그인하면 자동으로 앱으로 돌아와요. 아이폰·아이패드에서 안 돌아오면 그 페이지의 주소를 복사한 뒤 "클립보드에서 가져오기" 를 누르세요.

로그인 정보는 폰 안의 안전한 저장소(안드로이드 Keystore / iOS 키체인)에만 저장돼요.

계정이 없으면
  • 홈의 라디오(KBS·MBC·SBS·EBS 등)는 로그인 없이 들을 수 있어요.
  • 집에 NAS 가 있으면 라이브러리 → 서버 → "+ 추가"(SMB/WebDAV)로 그 안의 음악을 들을 수 있어요.
  • 무료 체험 계정은 30초 미리듣기만 나올 수 있어요. 확인된 건 아니에요.

4. 소리 나는지 확인

홈의 라디오 카드를 하나 탭해 보세요. 소리가 나면 설치는 끝이에요.

✅소리가 나요. 안 나면 이럴 땐 첫 항목.

5. (안드로이드) 화면 꺼도 안 끊기게

설정 → 재생 → "백그라운드 재생" 카드 에서 배터리 최적화 제외를 등록해 두세요. 안 하면 화면을 끈 뒤 재생이 끊길 수 있어요.

보이지만 안 눌러도 되는 것

  • 홈의 "다른 앱 소리를 렌더러로 재생" 카드 — 지금은 안 눌러도 돼요. 누르면 화면 녹음 권한을 물어요.
  • 재생 탭이 비어 있을 때 보이는 "디버그 대시보드" 문구 — 무시하세요(알려진 문제).
  • 한글 검색어를 영어로 보강한다는 안내 — 무시하세요. 그냥 한글로 검색돼요.

이럴 땐

재생을 눌러도 아무 반응이 없어요
홈 맨 위 카드를 보세요. 렌더러로 돼 있는데 집에 렌더러가 없으면 그래요. 카드 탭 → "단말 자체" 로 바꾸세요 (처음 켜면 → 2번).
첫 화면에 빨간 오류 알림이 떠요
"tidal 동기화 실패" 류면 로그인 전이라 뜨는 거예요. 무시해도 돼요.
렌더러가 목록에 안 보여요
폰과 렌더러가 같은 Wi-Fi 인지 보고, VPN 을 끄세요. 출력 장치 시트 위의 "렌더러 검색" 을 다시 눌러 보세요.
(아이폰·아이패드) 앱이 안 열려요
고장이 아니에요. 테스트용 빌드는 올린 지 90일이 지나면 열리지 않아요. TestFlight 앱에서 업데이트가 있으면 받고, 없으면 보낸 사람에게 새 버전을 달라고 하세요.
업데이트는 어떻게 받아요?
아이폰·아이패드는 자동 업데이트를 켰으면 알아서 들어와요. 안드로이드는 새 버전이 나오면 메일과 App Tester 알림이 와요 — 받아서 설치하면 덮어 깔리고 로그인·설정은 그대로예요. 지우고 다시 깔 필요 없어요.
문제를 알리고 싶어요
이 넷을 적어 보내 주세요: 앱 버전(설정 탭 아래쪽 빌드 정보의 숫자 — 안드로이드는 versionCode, 아이폰은 빌드 번호) · 기종 · 시각 · 하던 일. 아이폰·아이패드에서는 스크린샷을 찍으면 "베타 피드백 보내기" 가 바로 떠서 그걸로 보내도 돼요.
그만두고 싶어요
앱 안에서 로그아웃한 뒤 앱을 지우세요. 아이폰·아이패드는 로그인 정보가 키체인에 남을 수 있어서 로그아웃을 먼저 해요. 안드로이드에서 새 폰으로 옮길 땐 백업 복원 말고 새로 설치하세요 — 복원본은 앱이 죽는 알려진 문제가 있어요.
내 정보는 어디로 가요?
앱은 사용 기록이나 분석 데이터를 모으지 않아요(그런 라이브러리가 들어 있지 않아요). 음악은 Qobuz·Tidal 서버에서 바로 받아요. 하나만 예외인데, KBS 라디오는 만든 사람이 가진 서버(Cloudflare Worker)를 거쳐요. 그래서 KBS 를 틀면 만든 사람이 접속 IP 를 볼 수 있어요. 솔직하게 알려 드려요.

궁금한 건 보낸 사람에게 물어보세요. 재미있게 들으세요.
